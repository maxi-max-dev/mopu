# Third-party software and design references

Phone Harness source is MIT licensed. Dependencies keep their own licenses and are not relicensed by this repository.

| Project | Role | License / source |
|---|---|---|
| scrcpy | Downloaded Android server and documented video/control protocol; pinned version and SHA-256 in setup | Apache-2.0, https://github.com/Genymobile/scrcpy |
| Mobile MCP | Separately installed semantic Android tools | Apache-2.0, https://github.com/mobile-next/mobile-mcp |
| aiohttp | Python HTTP/WebSocket runtime | Apache-2.0, https://github.com/aio-libs/aiohttp |
| Android platform-tools / ADB | External prerequisite installed by the user | https://developer.android.com/tools/releases/platform-tools |
| OpenClaw | Optional host for the bundled adapter; not bundled | MIT, https://github.com/openclaw/openclaw |

The interface, SVG icons and synthetic preview illustration in this repository are original implementations. System fonts are referenced by CSS; no proprietary font files or Apple icons are bundled.

Visual research used [优设美地](https://allan.xin/?library=components), its Apple Navbar V002 / GlassSurface entries, and [Apple's Materials guidance](https://developer.apple.com/design/human-interface-guidelines/materials). No Skiper UI, React Bits or Apple component source is included. [BlueStacks' toolbar layout](https://support.bluestacks.com/hc/en-us/articles/360055672212-How-to-use-the-Side-toolbar-in-BlueStacks-5) informed the initial compact arrangement. No affiliation or endorsement is implied.
