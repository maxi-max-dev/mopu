会话设置

操作位置提示

用圆点、圆环和轨迹标出刚才的点击、长按或滑动。只显示在电脑上；提示输入已发出，是否生效以手机画面为准。输入文字不会显示具体内容。

提示大小

手动操作约 0.45 秒、助手约 0.9 秒淡出；连续操作时，上一处提示会快速消退。

实体屏幕指示灯

右侧按钮切换亮屏／息屏，投屏保持可操作。约每 1.5 秒读取实体面板状态，读数过期会显示待确认。这是系统读回，不是外部摄像头。

连接时息屏
安静模式

静音基础音频并关闭已识别的振动设置；空闲时降低并静音通话音频。接通或切换输出仍可能改变状态，详情显示实际音量和输出路径。退出后保留。

默认开启
关闭控制台后暂停

最后一个窗口关闭 12 秒后暂停。关闭此选项后，已取得控制权的助手可继续执行。

断线恢复

保留任务与进度，最多自动重连三次。恢复后仍暂停，由你交回助手再续接。

手机启动连接时可能短暂亮屏。电池温度不是 CPU 温度。设置读回不等于声学测量，也不能证明所有第三方应用均不振动。

最近事件

共用一台手机，各自执行任务

在对应助手的 MCP 配置中添加下面的命令。每个同时运行的助手使用独立标识。

phone-harness mcp --agent codex --name Codex
phone-harness mcp --agent claude --name "Claude Code"
phone-harness mcp --agent jarvis --name Jarvis
  1. 助手调用 phone_status 接入，然后添加任务。
  2. 你点击「交回助手」，原助手领取队首属于它的任务。
  3. 点击「我来操作」随时接管；交回后助手重新观察并续接。

控制台提供手机工具，不运行 AI 模型。OpenClaw / Jarvis 可安装随包附带的原会话续接插件；通用 MCP 助手需要保持任务执行或由宿主续接。外部助手尚未接入时，任务会保留等待。
