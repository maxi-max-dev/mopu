手机活动

尚未开启记录

只记录 App 名称/包名、前台停留与操作次数，不保存页面内容、输入文字、点击坐标、截图或录音。停留不等于持续使用，也不能确认操作者。约每 2 秒取样，短暂切换可能漏记；锁屏或读数中断即停止计时。连续 30 秒无新操作后合并提醒，附本段 App 及各自停留时长；提醒至少间隔 5 分钟。关闭会话、USB 断开或 Mac 休眠期间无法监测。

会话设置

操作位置提示

用圆点、圆环和轨迹标出刚才的点击、长按或滑动。只显示在电脑上；提示输入已发出，是否生效以手机画面为准。输入文字不会显示具体内容。

提示大小

手动操作约 0.45 秒、助手约 0.9 秒淡出；连续操作时，上一处提示会快速消退。

实体屏幕指示灯

右侧按钮切换亮屏／息屏，投屏保持可操作。约每 1.5 秒读取实体面板状态，读数过期会显示待确认。这是系统读回，不是外部摄像头。

连接时息屏
安静模式

静音基础音频并关闭已识别的振动设置；空闲时降低并静音通话音频。接通或切换输出仍可能改变状态，详情显示实际音量和输出路径。退出后保留。

默认开启
关闭控制台后暂停

最后一个窗口关闭 12 秒后暂停。关闭此选项后，已取得控制权的助手可继续执行。

断线恢复

保留任务与进度，最多自动重连三次。恢复后仍暂停，由你交回助手再续接。

手机启动连接时可能短暂亮屏。电池温度不是 CPU 温度。设置读回不等于声学测量，也不能证明所有第三方应用均不振动。

最近事件

接入 AI 助手

支持具备 MCP 或命令行工具的 AI，包括 Codex、Claude、Grok 和 Jarvis。每个同时执行的聊天使用独立标识。

MCP 接入

mopu mcp --agent my-ai-chat --name "My AI"

命令行接入

mopu call --agent my-ai-chat list
mopu call --agent my-ai-chat phone_session

检查接入

命令行会保留连接和控制权，无需另建桥接。参数用 --json @args.json 传入。若命令不在 PATH，本机入口为 ~/.local/share/phone-harness/venv/bin/mopu。

  1. 在原 AI 聊天里说明任务和授权范围。
  2. 助手调用 phone_start 创建整项授权，再用 phone_wait 领取手机；空闲时无需手动排队或交回。
  3. 先做无发送演练：max_deliveries: 0，只读屏验证连接。
  4. 你可随时接管。人工接管会停止授权，原助手核对进度后再续接。

Mopu 提供手机工具，不启动 AI 模型。助手必须保持执行，或由其宿主续接。工具返回成功不代表任务完成。

手机能力目录

先看设备提供哪些能力，再由原助手取得控制权执行。接口返回不代表任务完成。

删除任务

    移入回收站后可恢复。已有进度、结果和发送记录会保留；恢复不会自动执行。

    调整等待顺序

    只调整等待中的任务，当前正在执行的任务会继续。

    编辑任务要求

    保存后由原助手下次领取时读取。保留已有进度、调用计数和审批记录；不会自动执行或批准下一阶段。
