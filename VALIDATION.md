# Validation scope

Public acceptance descriptions are intentionally aggregated. Device identifiers, owner-specific activity, captured application contents and private runtime receipts are not release artifacts.

The existing software suite covers exclusive control, lease revocation, task budgets, observation provenance, transfer ownership, and recovery boundaries. Historical single-device checks exercised screen transport, navigation, text entry and result readback; they do not establish reliability across all devices or apps.

Physical input attribution, simultaneous human/agent use, incoming-call behavior and transport recovery need environment-specific acceptance. A passing unit test is not a physical-device result.

See [whole-task validation](docs/VALIDATION-0.19.1.md) for scoped results and outstanding checks. No user screenshots, activity logs, application notes or runtime state are included as evidence in this repository.
