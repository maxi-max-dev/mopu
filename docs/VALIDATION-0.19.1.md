# Mopu 0.19.1 acceptance — 2026-10-28

Runtime package: `0.19.1+stabletransfer`. The suffix identifies the retained stable file-transfer implementation.

## Evidence

- The public source passed 234 Python tests, 18 JavaScript tests and JavaScript syntax checks locally. Tests use isolated temporary state and mocked phone methods.
- Whole-task protocol tests completed 150 synthetic deliveries / 750 calls under one grant. This is not 150 real messages or job applications.
- Fresh stdio MCP and separate persistent CLI processes exercised task start, lease recovery, free heartbeat and finish. Concurrent CLI use, authorization replay, zero-send limits, pending deliveries, takeover and restart retention are covered.
- One connected G100 completed 206 read-only calls under one authorization, exceeding the old 200-call boundary. No phone input or outgoing delivery occurred. Completion returned human ownership.
- All 61 pre-existing task records and settings were unchanged across deployment. No queued job-search task was resumed.
- Isolated browser fixtures exercised the UI at 1280×800 and 850×618. The installed desktop showed the release version and distinguished unknown legacy outcomes from verified delivery counts.
- Runtime modules match the tested installed candidate. The stable transfer implementation is retained; the separate throughput optimization and experimental Android-resident runtime are excluded.

## Limits

MCP and shell execution are the supported integration routes. Every AI product/model is not independently certified; the host must remain running and able to use one of these routes. OpenClaw adapter tests do not prove a running gateway has reloaded the new catalog. Long-duration unattended operation, real outgoing bulk deliveries and other phones are not established by this acceptance.

Manual takeover, pause, disconnect, server restart and grant expiry still stop execution. Whole-task authorization is bounded and must reflect the user's actual instruction; it is not permission to renew itself or bypass a stop.
